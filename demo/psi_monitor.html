    PSI = Σ (a − e) · ln(a / e) over the 4 bins [0, 0.25), [0.25, 0.5), [0.5,
    0.75), [0.75, 1], with +0.5 added to every bin so an empty bin never gives
    ln(0). Sensor rates, filter, window, step, bins, smoothing and thresholds
    match the LogiEdge code. P(Normal) comes from a simple stand-in for the
    trained model, so exact values differ from the real M3.
